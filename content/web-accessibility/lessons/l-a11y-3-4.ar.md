في قسم قائمة الفنانين في Ticketly ثلاثة تبويبات، Friday وSaturday وSunday، مبنية من أزرار منسّقة تبدّل اللوحات عند النقر. بالفأرة كل شيء على ما يرام. أما بقارئ الشاشة فهي صفّ من ثلاثة أزرار لا علاقة بينها، ولا شيء يقول أيّ يوم معروض، واللوحات تتبدّل بصمت. لا يوجد عنصر `<tabs>` في HTML، وهذا هو ملعب ARIA.

## دليل ARIA Authoring Practices

يصف **دليل ARIA Authoring Practices ‏(APG)**، الذي تنشره W3C، نحو ثلاثين نمطًا شائعًا للـ widgets: الـ accordion، والـ combobox، ونافذة الحوار، والـ disclosure، والـ listbox، وزر القائمة، والتبويبات، والشجرة وغيرها. ولكل نمط يسرد الأدوار والحالات والخصائص، و**تفاعل لوحة المفاتيح** الدقيق الذي يتوقّعه المستخدمون. يتعلّم مستخدمو قارئ الشاشة هذه الأعراف عبر آلاف المواقع، فاتّباعها يعني أن الـ widget الذي تبنيه يتصرّف بالطريقة التي يعرفونها أصلًا.

تحذيران. أمثلة APG عروض توضيحية لا components جاهزة للإنتاج، فاختبرها في سياقك. وAPG نفسه يقول بتفضيل HTML الأصلي حيث يوجد. وهذا يستبعد عددًا مفاجئًا من الـ widgets المخصّصة.

## الـ Disclosure: الإظهار والإخفاء

أبسط نمط هو زر يُظهر منطقة ويُخفيها، مثل إجابات الأسئلة الشائعة في Ticketly. إن سمح التصميم بذلك، فعنصرا `<details>` و`<summary>` الأصليان يمنحانك الأمر كله دون أي سكربت:

```html
<details>
  <summary>How do refunds work?</summary>
  <p>You can get a full refund up to 14 days before the festival.</p>
</details>
```

وحين تحتاج إلى نسخة مخصّصة، فالحالة الأساسية هي `aria-expanded` على الزر:

```html
<h3>
  <button type="button" aria-expanded="false" aria-controls="refunds">How do refunds work?</button>
</h3>
<div id="refunds" hidden>
  <p>You can get a full refund up to 14 days before the festival.</p>
</div>
```

```js
button.addEventListener('click', () => {
  const open = button.getAttribute('aria-expanded') === 'true';
  button.setAttribute('aria-expanded', String(!open));
  panel.hidden = open;
});
```

يُعلن قارئ الشاشة "How do refunds work?, button, collapsed"، ثم "expanded". ولفّ الزر بعنوان يُبقي أسئلة الصفحة ضمن التنقّل بين العناوين.

## التبويبات

لنمط التبويبات أجزاء متحرّكة أكثر:

- حاوية عليها `role="tablist"` (واسم، مثل `aria-label="Festival days"`).
- كل تبويب عليه `role="tab"`، و`aria-selected="true"` أو `"false"`، و`aria-controls` تشير إلى لوحته.
- كل لوحة عليها `role="tabpanel"` و`aria-labelledby` تشير إلى تبويبها.
- **لوحة المفاتيح:** السهمان الأيسر والأيمن ينقلان بين التبويبات (مع الالتفاف عند الطرفين)، وHome وEnd يقفزان إلى الأول والأخير، وTab ينقل خارج الـ tablist إلى اللوحة.

النقطة الأخيرة تستخدم تقنية اسمها **roving tabindex** (الـ tabindex المتنقّل). وحده التبويب المحدَّد له `tabindex="0"`؛ والبقية لها `tabindex="-1"`. فيكون الـ tablist كله محطة Tab واحدة، وينقل معالج مفاتيح الأسهم التركيز والقيمة `0` بين التبويبات.

وهذه نسخة Ticketly:

```html title=ticketly/lineup.html
<div role="tablist" aria-label="Festival days">
  <button type="button" role="tab" id="tab-fri" aria-selected="true" aria-controls="panel-fri">Friday</button>
  <button type="button" role="tab" id="tab-sat" aria-selected="false" aria-controls="panel-sat" tabindex="-1">Saturday</button>
  <button type="button" role="tab" id="tab-sun" aria-selected="false" aria-controls="panel-sun" tabindex="-1">Sunday</button>
</div>
<div role="tabpanel" id="panel-fri" aria-labelledby="tab-fri" tabindex="0">…</div>
<div role="tabpanel" id="panel-sat" aria-labelledby="tab-sat" tabindex="0" hidden>…</div>
<div role="tabpanel" id="panel-sun" aria-labelledby="tab-sun" tabindex="0" hidden>…</div>
```

```js title=ticketly/tabs.js
const tabs = [...document.querySelectorAll('[role="tab"]')];

function select(tab) {
  for (const t of tabs) {
    const on = t === tab;
    t.setAttribute('aria-selected', String(on));
    t.tabIndex = on ? 0 : -1;
    document.getElementById(t.getAttribute('aria-controls')).hidden = !on;
  }
  tab.focus();
}

tabs.forEach((tab) => tab.addEventListener('click', () => select(tab)));

document.querySelector('[role="tablist"]').addEventListener('keydown', (event) => {
  const i = tabs.indexOf(event.target);
  const moves = { ArrowRight: i + 1, ArrowLeft: i - 1, Home: 0, End: tabs.length - 1 };
  if (!(event.key in moves) || i === -1) return;
  event.preventDefault();
  select(tabs[(moves[event.key] + tabs.length) % tabs.length]);
});
```

يستخدم هذا الكود **التفعيل التلقائي (automatic activation)**: الانتقال بالأسهم إلى تبويب يُظهر لوحته فورًا، وهو ما يوصي به APG حين تُعرض اللوحات دون تأخير. أما إن كانت اللوحة تحتاج إلى تحميل بيانات، فاستخدم التفعيل اليدوي بدلًا منه: الأسهم تنقل التركيز فقط، وEnter أو Space يحدّد التبويب. تحصل اللوحات على `tabindex="0"` لأنها لا تحتوي عناصر قابلة للتركيز خاصة بها؛ وهذا يمنح Tab مكانًا يصل إليه.

:::mistake التبويبات للتنقّل
إن كان كل «تبويب» يحمّل عنوان URL مختلفًا، فهو ليس widget تبويبات؛ بل تنقّل يشبه التبويبات. استخدم روابط داخل `nav` مع `aria-current="page"` على الرابط الحالي. عندها يستطيع المستخدمون فتح الصفحات في تبويبات جديدة ويعمل زر الرجوع.
:::

## زر القائمة، ومتى لا تستخدمه

نمط **زر القائمة (menu button)** في APG زر عليه `aria-haspopup="menu"` و`aria-expanded` يفتح عنصرًا عليه `role="menu"` يضمّ أبناء عليهم `role="menuitem"`. مفاتيح الأسهم تتنقّل بين العناصر، وEscape يُغلق القائمة ويعيد التركيز إلى الزر. وهو مناسب لقوائم الأفعال على طريقة التطبيقات، مثل قائمة "⋯" في Ticketly على حجز ما، وفيها "Download tickets" و"Transfer" و"Cancel booking".

لكنه خاطئ لتنقّل المواقع. يخبر الدور `menu` قارئات الشاشة بأن تتوقّع سلوك تطبيقات سطح المكتب: فتبدّل أنماط التفاعل وتُعلن العناصر على أنها عناصر قائمة لا روابط. أما لقائمة "Events" المنسدلة في الترويسة المليئة بالروابط، فاستخدم **disclosure**: زرًّا عليه `aria-expanded` يكشف قائمة عادية من الروابط. كود أبسط، ويتصرّف كما يتوقّع مستخدمو المواقع.

:::tip الـ popover يساعد في المظهر لا في الدلالة
خاصية `popover` في HTML مع `popovertarget` تمنحك العرض في الطبقة العليا والإغلاق الخفيف (light dismiss) مجانًا. وحين يفتح الزرُّ الـ popover بطريقة تصريحية عبر `popovertarget`، تكشف Chrome وEdge وFirefox وSafari حالة التوسيع أو الطيّ لذلك الزر تلقائيًا، فلا تُضِف `aria-expanded` بنفسك. أما إن فتح السكربت الـ popover بـ `showPopover()`، فلا يُكشف شيء وعليك أن تدير `aria-expanded` يدويًا. وفي الحالتين لا يقرّر الـ popover النمط الذي تبنيه: ما زلت أنت من يختار دلالة الـ menu أو الـ disclosure ويضيف دعم لوحة المفاتيح المطابق لها.
:::
